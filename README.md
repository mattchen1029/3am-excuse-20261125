A Python program that writes one excuse line — the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — to `/output/entry.txt`, for make.fun's "The 3 AM Excuse" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
